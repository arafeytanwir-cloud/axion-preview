# Axion website — GitHub Pages preview

This is a separate, static-hosting copy of the Axion website. English and Arabic content, layouts, theme, logos, photographs, fonts, navigation, and certification tabs are preserved. The production `axion-website` directory is not used or modified by this preview.

## Upload to a GitHub repository

1. Upload **the contents of this folder** into the repository root, including the hidden `.github/` folder, `src/`, `public/`, `package.json`, and `package-lock.json`. Do not put this whole folder inside another repository subfolder.
2. Open the repository's **Settings → Pages** and choose **GitHub Actions** as the source.
3. The included **Deploy static preview to GitHub Pages** workflow runs after uploads to the default branch. You can also start it from **Actions → Deploy static preview to GitHub Pages → Run workflow**.
4. Open the URL shown by the completed deployment.

No username, repository name, API key, or source-code URL needs to be edited. The workflow reads the exact Pages origin and repository base path automatically. Both `https://USER.github.io/REPOSITORY/` and root-hosted `https://USER.github.io/` sites are supported.

Nothing in this folder initializes a repository, commits, or pushes anything. The workflow only builds/deploys when **you** upload it to GitHub and enable Pages.

## Local preview

Requires Node.js 24 (or at least 22.12).

```bash
npm ci
npm run build
npm run preview
```

To test a repository subpath locally:

```bash
PAGES_SITE=https://example.github.io PAGES_BASE=/my-preview npm run build
npm run test:preview
PAGES_BASE=/my-preview npm run preview
```

Then open the preview server at `/my-preview/`, or `/my-preview/ar/` for Arabic. Without `PAGES_BASE`, local builds use `/`.

## Static-hosting adaptations

- The Cloudflare adapter, Worker configuration, runtime bindings, API routes, and local secret files are excluded. The build generates only static files in `dist/`.
- Internal links, language-switcher links, assets, favicons, and locale detection support the Pages repository prefix.
- All imported images are optimized ahead of time; no image API is required.
- The contact form looks the same, but submission only displays a localized static-preview notice directing visitors to the existing contact email. It does not send email, call the production API, or pretend a message was sent.
- Existing production canonicals and social metadata are retained. Arabic remains non-indexable by default, as in the original. The Pages sitemap is generated for the preview host.
- `.nojekyll` is included for static asset compatibility.

## Checks

```bash
npm run check
npm run build
npm run test:preview
```

`test:preview` checks all generated English/Arabic routes, the static-only output, repository-prefixed local links/assets, and section anchors. Neither the build nor these checks needs the original application folder.

The upload copy intentionally contains no `.git/`, `node_modules/`, `dist/`, API secrets, `.env`, `.dev.vars`, or Cloudflare runtime artifacts. Dependencies and output are generated by the workflow.
